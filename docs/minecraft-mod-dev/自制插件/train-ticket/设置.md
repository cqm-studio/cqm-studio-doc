# 配置说明（TrainTicket）

将下列配置放入 `plugins/TrainTicket/config.yml`。这是与当前 v1.3.x 代码一致的精简配置示例（请按需修改）：

```yaml
web:
  port: 2345        # Web 管理面板监听端口；留空或删除此键表示不启用面板

sync:
  stations_url: ""   # 站点同步地址（JSON API），留空则跳过站点同步
  lines_url: ""      # 线路同步地址（JSON API），留空则跳过线路同步
  log: false          # 当同步地址为空时是否输出“跳过同步”信息（默认 false）

economy:
  enabled: true       # 是否启用通过 Vault 扣款（插件需同时安装 Vault 与 Economy 插件）

security:
  web-token: ""      # 可选：为 Web 面板设置访问 token；为空则无认证

update:
  auto_enable: false            # 是否启用自动更新（从 Modrinth 拉取并下载）
  check_interval_minutes: 60    # 自动更新检查间隔（分钟）
  modrinth_project: "H8DKfMWO" # Modrinth 项目 ID（默认填项目占位符）
  include_beta: false           # 是否包含 beta 版
  include_alpha: false          # 是否包含 alpha 版
  auto_apply: false             # 下载后是否尝试热应用（可能失败，建议重启）
  target_mc_version: ""        # 目标 Minecraft 版本，必须配置以启用检查
```

重要说明（与代码行为一致）：

- 若 `web.port` 为空或不存在，Web 面板不会启动；默认端口为 2345。
- 若 `sync.stations_url` 或 `sync.lines_url` 为空，插件将跳过对应的云端同步。
  - 使用 `sync.log: true` 可以在跳过时输出一条日志提示；默认值为 false。
- 当前插件在服务器启动后会创建插件数据目录（`plugins/TrainTicket/`）并写入默认配置项（仅在缺失时写入，不会覆盖已有配置）。
- 自动同步（SyncTask）目前由插件内部调度，默认周期为 30 秒（600 ticks），该间隔在目前代码中为固定值并非通过上方配置项调整。
- 自动更新（update.*）功能需要设置 `update.target_mc_version` 才会进行版本匹配检查；下载/替换过程会尝试备份旧 jar 并使用原子移动以降低风险，但仍建议在测试环境验证后再在生产服启用 `auto_apply` 或 `auto_enable`。

安全建议：若面板对公网可达，请务必配置 `security.web-token` 并在反向代理层增加认证/访问控制。
